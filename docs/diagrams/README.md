# Diagrams

The architecture diagram of the main README is generated by a script (Python standard library only):

| Script | Output |
|---|---|
| `architecture.py` | `docs/architecture.svg` |

```powershell
python docs/diagrams/architecture.py
```

Boxes, arrows and texts are placed by coordinates in the script; `svglib.py` holds the drawing helpers. Icons in `docs/icons/` are embedded in the SVG file, because GitHub renders SVG as images that cannot load external files.
